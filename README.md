# 📊 Sales Performance Analysis

## 🛠️ Tools Used
- Microsoft Excel
- Google Sheets

## 📈 Project Overview
This project analyzes the sales performance of a US Real Estate. 
It explores trends and profit margins using pivot tables and interactive dashboards.

## ✅ What I Learned
- How to clean messy Excel data using formulas
- How to summarize KPIs using pivot tables
- How to visualize insights in Tableau
